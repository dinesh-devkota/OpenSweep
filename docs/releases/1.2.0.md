## OpenSweep 1.2.0

OpenSweep now offers guided Windows care alongside cleanup, startup management, storage analysis, and updates. The interface uses native Windows typography, quieter colors, and consistent rounded corners in light and dark themes.

### New and improved

- **Windows care:** practical guidance for startup, low disk space, notifications, restart timing, app permissions, and system repair. Open the relevant Windows controls, and copy or save a local system-information report.
- **Review-first health overview:** inspect cleanup, startup, updates, and drive space. “Review cleanup” opens a fresh preview; registry changes remain a separate Advanced tool.
- **Conservative cleanup defaults:** Recycle Bin contents, crash reports, dumps, logs, DNS, thumbnails, and shader caches require deliberate selection. Existing saved selections are retained; browser graphics caches have a separate opt-in category.
- **Startup search and export:** search names, publishers, and commands; filter enabled, disabled, or unknown entries; export the visible list. Partial reads are shown explicitly.
- **Storage export:** save the largest-file list as CSV with full paths, recorded sizes, scan time, and unreadable-folder counts.

### Reliability fixes

- Correct winget column parsing for wide Unicode characters; reject ambiguous or shortened package identifiers.
- Clear stale update results after failed or cancelled checks and require a successful check before installation.
- Preserve and redirect an existing scheduled cleaner when installing the portable app.
- Include the previous review's cleanup path protections, validated registry backups, duplicate verification, and malformed-path regression fix.

### Validation and upgrade notes

The upgrade passed 65 managed regression checks on Linux and 64 on Windows, with one Windows symbolic-link fixture skipped. The Windows application build completed with zero warnings or errors.

Review your saved cleanup selection after upgrading, particularly if you use scheduled cleaning. Startup management covers Run keys and Startup folders. Exported startup and storage reports can include commands and full file paths.

Interactive Windows rendering and operating-system actions still need a smoke test. Installer descendants can delay cancellation; Windows Update cancellation waits for its current synchronous stage to finish.
