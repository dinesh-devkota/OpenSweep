## OpenSweep 1.6.0

Android cleanup now offers visual file review, more useful categories, and recoverable media removal.

- **Visual review:** photo/video thumbnails, file dates, name/folder search and file-type filters. Open a read-only preview or choose which duplicate copy to keep.
- **More cleanup choices:** screenshots, old downloads (7, 30, 90 or 180 days), APK installers and videos of at least 100 MiB. Nothing is preselected.
- **Protected folders:** exclude a file's folder and its contents from scans and direct cleanup, including scheduled scans.
- **Trash and restore on Android 11+:** send supported, indexed photos, videos and audio to Android's Trash after system confirmation. Restore recorded items after reopening the app, or explicitly empty OpenSweep's recorded trash. Each request handles up to 100 eligible items.
- **Clear deletion choices:** unsupported files stay in place when requesting Trash. Permanent deletion requires its own confirmation. Trashed files still occupy storage until deleted or expired by Android.
- **Safer releases:** automated device checks exercise previews, folder protection, duplicate preservation, cancellation and trash/restore across process restart. The release workflow also requires Windows regression checks.

Install **OpenSweep.apk** over your current installation and choose **Update**. The Android application ID and signing certificate are unchanged. Android 8–10 keep the new review features and reviewed permanent deletion; system media trash requires Android 11 or newer.

Private app data and system files remain protected by Android. Optional Shizuku cache trimming is unchanged. Windows application behavior is unchanged in this release.
