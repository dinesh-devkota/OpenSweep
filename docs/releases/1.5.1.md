## OpenSweep 1.5.1

The app is named **OpenSweep** again. This update restores the name across Windows, Android, the website, repository descriptions, and release downloads.

- **Android:** install **OpenSweep.apk** over SqueakySift and choose **Update**. The application ID and signing certificate are unchanged, so permissions and preferences remain associated with the same app.
- **Windows:** run **OpenSweep-Setup.exe** over the existing installation, or use **OpenSweep.exe** as a portable app. The installer identity, saved settings, backups, and scheduled task remain compatible; owned shortcuts use the OpenSweep name again.
- **Existing links:** SqueakySift download filenames remain available as identical compatibility copies.

All features from 1.5.0 remain: full shared-storage permission setup, duplicate groups and keeper selection, scan progress and coverage, shared-cache controls, app management, and optional Shizuku cache trimming.
