## OpenSweep 1.3.0

OpenSweep now runs on Android 8.0 and newer. Install **OpenSweep.apk**, then choose a folder in the Android file picker.

- Scan the folder and its subfolders for temporary files ending in `.tmp` and desktop metadata named `Thumbs.db` or `.DS_Store`.
- Review each matching file’s path and size when available. Select the files to remove and confirm permanent deletion. OpenSweep rechecks each selection before deleting it and reports how many it removed.
- Scan and clean on your device. The Android app works without an internet connection and uses only the folder access you grant.

The Android build pipeline runs unit tests and lint, creates an installable test APK, and verifies the signature of the release APK before publication.
