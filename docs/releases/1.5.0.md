## SqueakySift 1.5.0

This release improves Android storage setup and duplicate cleanup, and adds optional Shizuku cache trimming. Install the signed APK over version 1.4.0 to update.

- Request full shared-storage access at setup and show its status on the home screen. Recover from permanently denied storage permission on older Android versions through app settings.
- Find duplicate files from the top of the home screen. See groups, extra copies, and removable space; select extras and choose which copy to keep before confirming deletion.
- Follow scan progress and inspect coverage, protected locations, and inaccessible volumes. Android bookkeeping files and synthetic media paths are excluded from duplicate suggestions.
- Revalidate duplicate contents and the chosen keeper before deletion. Refresh Android’s media index after successful deletion; gallery updates may complete asynchronously.
- Optionally authorize Shizuku and ask Android to trim eligible app caches across the device. The operation is bounded and reports the request result and observed free-space change. It does not use the app-data clearing command.

Android’s normal all-files permission covers shared files, not the operating system or other apps’ private data. Shizuku ADB mode also does not unlock all private files. Deeper cache trimming is a separate user-confirmed system operation.

The Windows tools are unchanged in this release. Existing installation identities, Android signing certificate, saved settings, and legacy download links are retained.
