## SqueakySift 1.4.0

OpenSweep is now **SqueakySift**. Download **SqueakySift-Setup.exe** for Windows, **SqueakySift.exe** for a portable copy, or **SqueakySift.apk** for Android 8.0 and later.

- **Android** — Open the signed APK and choose **Update** to upgrade an existing OpenSweep installation. The application ID and signing certificate are the same as in 1.3.0.
- **Windows** — Run the installer over the old version. Existing settings, registry backups, and scheduled cleanup use the same locations. The app and its shortcuts now display the new name.
- **Downloads** — The previous OpenSweep filenames are also included for people using existing download links.

### Android storage and maintenance

- Scan shared internal storage and accessible SD cards using Android's all-files permission.
- Review junk files, large files, and SHA-256-verified duplicates before deletion.
- Inspect installed apps and optionally permit usage access for app cache/data size and last-used statistics.
- On Android 11 and later, ask Android to clear shared app caches through its system confirmation. Open individual app settings to manage private app caches.
- Open uninstall confirmation, store pages, storage, battery, security, and system update settings.
- Choose Light, Dark, or System appearance.
- Enable a daily scan while charging and receive a notification to review a fresh scan.

Android reserves system files and app-private storage for its own management controls. The storage picker restrictions in version 1.3.0 are addressed by the explicit all-files-access flow.
